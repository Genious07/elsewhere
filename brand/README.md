# Elsewhere identity

The monogram is an E in perspective, with its right edge opening like a door. It connects the collection’s two ideas: a recognisable author’s mark and an entrance into unfamiliar browser worlds.

| Asset | Use |
| --- | --- |
| `logo-dark.svg` | Square logo on a midnight background |
| `logo-light.svg` | Square logo on a pale background |
| `mark.svg` | Transparent mark for dark surfaces |
| `cover.svg` | Wide GitHub README cover, 1280 × 420 |
| `social-preview.png` | Repository social image, 1280 × 640 |

The logo paths are original editable vectors. Lettering in the cover uses a system Arial/Helvetica sans-serif stack; the monogram has no font dependency.

| Colour | Hex | Role |
| --- | --- | --- |
| Midnight | `#152027` | Background |
| Chalk | `#F0F4ED` | Primary mark and lettering |
| Iris | `#B7B9FF` | Open edge and accent |
| Slate | `#728194` | Receding plane |
| Apricot | `#FF986F` | Small point of focus |

Keep the proportions. Leave at least one stroke-width of clear space around the mark. Use the light version on pale surfaces; do not add glow, stretch the door, or use the monogram as a repeating pattern.

The social image is supplied as an upload-ready asset. It does not change the owner's GitHub profile avatar.
